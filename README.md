# 도름스 체험학습

체험학습 일정과 안내사항을 한 페이지에 담아 링크와 QR로 나눠 주는 웹앱입니다.
장을 한 장씩 넘기면 그 순서가 곧 시간표이자 동선이고, 지도가 그 구간을 따라갑니다.
학생이 장소마다 쓴 느낀 점은 생기부 AI 살핌에 바로 올릴 수 있는 엑셀 파일로 모입니다.

## 무엇을 하나

| 누가 | 하는 일 |
|---|---|
| 선생님 | 여행 제목·출발일·몇 박을 정하고, 일차마다 시각·활동명·주소·안내사항을 넣는다. 주소를 찾으면 지도에 찍히고, 장소 사이 길은 저장할 때 계산된다. 링크·QR을 나눠 준다. 고친 내용은 같은 링크에 15초 안에 반영된다(앞단 캐시 5초 + 늦은 갱신 10초). |
| 학생 | 로그인 없이 링크를 열어 장을 넘긴다. 장소마다 느낀 점을 쓰고, 다녀와서 「내 느낀 점 저장」으로 `학번_이름_느낀점.txt` 파일 하나를 받아 낸다. |
| 보호자 | 같은 링크로 일정을 따라간다. 해외 여행이면 한국 시각이 함께 보인다. |
| 선생님(다녀와서) | 학생 파일 여러 개를 한꺼번에 놓으면 살핌 설문 양식 엑셀 하나로 받는다(첫 시트 `설문응답`, `학번 · 이름 · 장소별 질문`). |

## 개인정보와 PIN

- 안내 문서는 링크를 아는 누구나 볼 수 있다. 휴대전화 번호·주민등록번호·이메일 주소가 들어가면 저장하지 않는다(`src/lib/pii.ts`, 서버도 같은 검사).
- 학생 학번·이름·느낀 점은 학생 브라우저(localStorage)와 학생이 내려받은 파일에만 있다. 서버로 보내지 않는다. 느낀 점 모으기도 선생님 브라우저 안에서만 처리한다.
- PIN 원문은 저장하지 않는다. 서버가 PBKDF2-SHA256(여행마다 다른 salt + 서버 비밀값 `PIN_PEPPER`)으로 바꾼 값만 비공개 저장소에 둔다. 확인은 서버 함수에서만 한다.
- 같은 인터넷 주소에서 5번 틀리면 15분 잠기고, 계속 틀리면 잠금이 두 배씩 길어진다(최대 24시간). 다른 주소의 선생님은 막히지 않는다. 여러 주소에서 나눠 시도해 여행 전체로 50번 틀리면 1시간 잠긴다. 틀린 횟수는 조건부 쓰기(ETag)로 세어 동시에 넣어도 새지 않는다.
- PIN은 6~12자리 숫자. 같은 숫자 반복·연속 숫자·흔한 조합·날짜 모양(생일, 여행 날짜)은 받지 않는다.
- PIN이 맞으면 그 기기에 무작위 편집 열쇠만 남는다(서버엔 해시). 기본은 창을 닫으면 끝나고(서버에서도 12시간), 「이 기기 기억하기」를 고르면 30일. PIN을 바꾸거나 「모든 기기에서 편집 끝내기」를 누르면 모든 열쇠가 무효가 된다.
- 처음 만들 때 한 번 보여 주는 복구 코드로 PIN을 다시 정할 수 있다. 쓴 복구 코드는 그 자리에서 새 코드로 바뀐다. 누가 PIN을 일부러 틀려 잠가도 복구 코드는 막히지 않는다(복구 코드 틀림은 주소별로 따로 센다).
- 여행은 끝난 날로부터 1년 뒤 매일 도는 정리 작업이 지운다.

## 구조

```
api/                 Vercel 함수(같은 코드를 개발 서버도 쓴다)
  trip.ts            /api/trip  읽기·만들기·저장·PIN·복구·지우기
  manifest.ts        /t/<id>/manifest.webmanifest (여행별 홈 화면 앱)
  cleanup.ts         매일 정리(Vercel Cron, CRON_SECRET)
  _lib/service.ts    저장·PIN 규칙(시험: tests/service.test.ts)
  _lib/store.ts      저장소: Vercel Blob(비공개) · 개발용 파일 · 시험용 메모리
src/
  trip/schema.ts     여행 문서 구조(zod, 화면·서버 공용)
  trip/derive.ts     문서 → 장 흐름(출발 전 → 일차 → 다녀와서)
  features/viewer    학생·보호자·선생님이 보는 화면
  features/editor    편집기(장소 찾기 Nominatim, 길 계산 OSRM·Transitous)
  features/collect   느낀 점 모으기 → 살핌 양식 엑셀
  lib/reflectionFile.ts  학생 파일 형식(읽는 글 + 맨 끝 데이터 한 줄)
public/sample/       랜딩 샘플(가상 학교의 경주 2박 3일, scripts/make-sample.mjs)
```

## 내 컴퓨터에서

Node.js 22 이상.

```bash
npm install
npm run dev      # http://localhost:5191  (저장은 .data/ 폴더)
npm test         # 서버 규칙·파일 형식·모으기 시험
npm run build    # 검사(가드) + 타입 검사 + 빌드
```

## 직접 배포하기(Vercel)

1. 이 레포를 Vercel 프로젝트로 연결한다(프레임워크 Vite, `vercel.json` 그대로).
2. Storage에서 Blob 저장소를 **Private**로 만들어 프로젝트에 연결한다(`BLOB_READ_WRITE_TOKEN`이 생긴다).
3. 환경 변수 `PIN_PEPPER`(무작위 32자 이상)와 `CRON_SECRET`(무작위)을 넣는다.
4. 배포한다. 함수 리전은 `vercel.json`의 `icn1`(서울)이다.

지도 타일은 OpenFreeMap, 주소 찾기는 Nominatim, 길 계산은 OSRM 공개 서버(버스·자동차·걷기)와 Transitous(대중교통·지하철·기차, 공개 시간표)를 쓴다. 공개 서버 규칙(초당 1회, 자동완성 금지)을 지키도록 찾기 단추를 눌렀을 때만 부르고, 길은 선생님이 저장할 때 바뀐 구간만 한 번 계산해 지도에 선으로 그린다. 걸리는 시간은 계산하지 않고 선생님이 직접 적는다(5분씩 늘리고 줄이는 단추도 있다). 적지 않은 구간은 학생 화면에 시간이 나오지 않는다.

Transitous는 오픈소스·비상업 앱에 열린 공동체 서비스다. 직접 띄워 쓰는 곳도 사용 규칙(https://transitous.org/api/)을 지키고, 화면에 출처(https://transitous.org/sources/)를 밝혀야 한다. 바깥 주소를 새로 부르면 `vercel.json`의 CSP `connect-src`에도 넣어야 배포본에서 막히지 않는다(`npm run guard`가 확인한다).
